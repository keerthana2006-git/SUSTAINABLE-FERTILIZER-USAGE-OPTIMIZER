# Sustainable Fertilizer Usage Optimizer

A command-line data-science prototype that predicts crop yield from soil, weather, crop, and applied N/P/K fertilizer, then searches for fertilizer rates that trade off predicted yield against total fertilizer input.

## Important data limitation

The supplied `data/fertilizer_dataset.csv` contains ten illustrative starter rows, not verified farm measurements, and does not record applied fertilizer rates. It is retained as the original example, but is not suitable for training this optimizer. The project therefore uses a reproducible, 3,000-row **synthetic** dataset generated by `generate_data.py`. Its values and resulting model scores/recommendations are for demonstrating data-science methods only. They are not agronomic advice, field-validated findings, or evidence of real-world fertilizer savings. Replace the synthetic data with a documented, representative field dataset and validate locally before practical use.

## Setup and run

```powershell
python -m pip install -r requirements.txt
python generate_data.py
python main.py
```

`main.py` generates the default dataset if it is absent. To regenerate it with a different size and seed:

```powershell
python generate_data.py --rows 5000 --seed 7
python main.py --seed 7
```

The optimizer uses a random-forest regression pipeline with one-hot crop encoding, an 80/20 held-out test split, and a mean-prediction baseline. It reports MAE, RMSE, and R-squared, then searches a bounded N/P/K grid for each crop using the objective `predicted yield - input penalty * total fertilizer`. The penalty is configurable with `--input-penalty`; its default is a demonstration setting, not a calibrated economic or environmental value.

## Outputs

- `data/synthetic_fertilizer_dataset.csv`: generated training data
- `models/fertilizer_yield_model.joblib`: fitted model pipeline
- `models/model_metrics.json`: held-out model and baseline metrics
- `models/recommendations.csv`: recommendations for the median dataset soil/weather profile
- `graph/model_diagnostics.png`: held-out predictions and feature importances

Run the focused tests with `python -m unittest`.
